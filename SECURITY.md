# Security

Waraq processes documents on the user's device. If you find a way for a document or a web page to read files,
run code, or send data somewhere without the user's action, please report it privately through
**GitHub → Security → Report a vulnerability** on this repository rather than opening a public issue.
Please do not include confidential documents; a minimal PDF that shows the problem is best.

Supported versions: the latest release (`app/`, 0.3.x) and the development branch of Waraq 1.0 (`next/`).
